¿Qué es la Recursión de cola (tail recursion)?
Es cuando la llamada recursiva es la última operación que hace la función, eso permite optimizar la memoria

¿Cuál es la relación entre foldr y foldl con este tipo de recursión?
foldl es recursión de cola porque acumula el resultado. foldr no lo es porque evalúa después
